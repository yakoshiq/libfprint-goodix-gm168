# Per-device provisioning

## Why provisioning is required

The GM168 transport uses a device-specific TLS PSK. Image correction also uses
per-pixel calibration captured for that physical sensor. Neither belongs in the
driver source or a distribution package.

## Private state layout

```text
/etc/goodix-gm168/
├── psk.bin              32 bytes
├── calib_windows.dat    140464 bytes
├── cal_scale.bin        10240 bytes
└── fdt_thresholds.bin   6 bytes, generated by the Linux driver
```

Required ownership and permissions:

```text
/etc/goodix-gm168                 root:root 0700
/etc/goodix-gm168/*               root:root 0600
```

The driver refuses to create sensitive state in an existing directory that is
a symlink, owned by another user, or accessible by group/other users.

## Sealed bootstrap

When `psk.bin` is absent, activation can read the 324-byte DPAPI-sealed object
from the sensor and save `sealed.bin` privately. This operation reads existing
sensor state; it does not provision or rotate the PSK.

The sealed object can normally be decrypted only under the Windows security
identity that provisioned it. Reinstalling Windows may change that identity and
make the old object unusable. Do not publish `sealed.bin` even though it is
encrypted.

This repository does not yet include a reviewed cross-machine transfer/unseal
utility. It also intentionally excludes the model-wide WhiteBox derivation
implementation.

## Calibration

The reference driver requires both calibration files for reliable minutiae on
the tested unit. They were recovered from the active Windows biometric process
and validated structurally and against the Windows output formula.

There is currently no safe, general calibration acquisition tool in this public
tree. Do not use calibration from another laptop: portability is unverified and
it may materially degrade matching.

## Recovery rule

Always retain a password authentication path. A fingerprint reader, its PSK, or
its calibration may become unavailable after firmware, Windows, hardware, or
system-library changes.
